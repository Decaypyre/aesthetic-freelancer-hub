
# Aesthetic Freelancer Portfolio

A modern, responsive portfolio website for freelancers showcasing services in web development, UI/UX design, video editing, social media management, and content creation.

## Features

- **Responsive Design:** Fully responsive layout that looks great on all devices
- **Modern Aesthetics:** Clean, elegant design with subtle animations and transitions
- **Service Showcase:** Dedicated sections for each service offering
- **Portfolio Gallery:** Filterable project showcase with categories
- **Contact Form:** Easy-to-use contact form with validation
- **Smooth Scrolling:** Enhanced user experience with smooth scroll between sections

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Shadcn UI Components
- Lucide Icons
- React Router

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Page components
- `/src/lib` - Utility functions and helpers

## Customization

You can customize this portfolio by:

1. Updating personal information in the Hero and About sections
2. Adding your own projects to the Portfolio section
3. Modifying services to match your specific offerings
4. Changing the color scheme in tailwind.config.ts
